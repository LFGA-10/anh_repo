Expected answer structure:
WASTE DISPOSAL PROTOCOL

1. Waste Classification System
• Color-coded bins for different waste types
• Clear signage and staff training
2. Biodegradable Waste Management
• Organic waste (animal bedding, food waste) → composting
• Animal tissues/carcasses → incineration or licensed rendering
• Approval for burial where permitted
3. Non-biodegradable Waste Management
• Plastics, glass, metals → recycling where possible
• Clean recycling vs contaminated waste separation
4. Hazardous/Sharps Waste
• Needles/syringes → sharps containers, incineration
• Chemical waste → licensed hazardous waste contractor
• Pharmaceutical waste → return to supplier/incineration
5. Safety Considerations
• PPE for waste handlers
• Regular collection schedule
• Secure storage before disposal
• Documentation and audit trail
